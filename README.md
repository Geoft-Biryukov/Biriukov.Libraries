# Biriukov.Libraries
Библиотека на C# (.NET 8.0) математических подпрограмм для моделирования задач управления угловым движением твердого тела (космического аппарата (КА)). Библиотека состоит из следующих модулей:

1. [[Biriukov.Mathematics]] - математические объекты и функции;
2. [[Biriukov.Orientation.Core]] - различные параметры ориентации (кватернионы, углы Эйлера-Крылова, матрицы направляющих косинусов) и алгоритмы перехода от одних параметров к другим;
3. [[Biriukov.OrdinaryDifferentialEquations]] - методы численного решения задачи Коши для системы обыкновенных дифференциальных уравнений;
4. [[Biriukov.OptimalControl]] - задачи оптимального управления.

# Biriukov.Mathematics
Содержит основные математические сущности:
- `Vector3D` - вектор в пространстве
- `Angle` - обертка для углов (рад/гр)
- `MathAngle` - функции для `Angle` (тригонометрия и др.)

# Biriukov.Orientation.Core
Параметры ориентации:
- `Quaternion`
- `EulerAngles`
- `DirectionCosineMatrix`

# Biriukov.OrdinaryDifferentialEquations

## Основные компоненты

### 1. **Ядро библиотеки**

- `StateVector` - центральный класс для представления вектора состояния
    
- `IDifferentialEquation` - интерфейс для определения правых частей ОДУ
    
- `InitialValueProblem` - инкапсулирует задачу Коши
    

### 2. **Решатели ОДУ**

- `IOdeSolver` - единый интерфейс для всех решателей
    
- `EulerMethodSolver` - явный метод Эйлера 1-го порядка
    
- `Rk4Solver` - классический метод Рунге-Кутта 4-го порядка
    

### 3. **Настройки решателей**

- `IOdeSolverSettings` - маркерный интерфейс (internal)
    
- `EulerMethodSettings` - настройки для метода Эйлера
    
- `Rk4Settings` - настройки для метода Рунге-Кутта
    

### 4. **Классы-результаты**

- `Variables` - пара (время, состояние) для возврата результатов
    
- `DifferentialEquationSolution` - альтернативный класс для результатов
    

### 5. **Дополнительные интерфейсы**

- `IAnalyticalSolutionProvider` - для сравнения с аналитическим решением
